# Bank Account Management System

A simple **Bank Account Management System** built using **Python and Object-Oriented Programming (OOP)**.

This project demonstrates basic banking operations such as password verification, checking balance, depositing money, and withdrawing/debiting money.

## Features

- Password verification
- Check account balance
- Deposit money
- Withdraw / debit money
- Display account details
- Basic balance validation
- Built using Python OOP concepts

## Technologies Used

- Python 3
- Object-Oriented Programming (OOP)

## OOP Concepts Used

This project demonstrates the following OOP concepts:

- Class – `BankAccount`
- Object – `account`
- Constructor – `__init__()`
- Encapsulation – Private password using `__password`
- Methods – `deposit()`, `withdraw()`, `check_balance()`, etc.
